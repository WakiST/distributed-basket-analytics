# BasketNet

Учебный проект по теме «Распределённая сетевая система сбора, агрегации транзакций и аналитической обработки потребительской корзины».

## Технологии

Python 3.10+, стандартная библиотека. Планируется использовать TCP для заданий и уведомлений, UDP для heartbeat и многопоточный брокер.

## План реализации

1. Вычислительные операции над транзакциями и корзинами, проверка данных и тесты.
2. Сетевой протокол, брокер с приоритетной очередью и вычислительные узлы.
3. Клиент, подписки на статусы и проверка отказоустойчивости.
4. Графический интерфейс, локальная демонстрация и документация.
