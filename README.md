# BasketNet

Учебный проект по теме «Распределённая сетевая система сбора, агрегации транзакций и аналитической обработки потребительской корзины».

Текущий этап — вычислительное ядро и проверка входных данных. Требуется Python 3.10+, внешних зависимостей нет.

## Реализованные операции

| Операция | Назначение |
|---|---|
| `sum` | Сумма массива либо расчёт чека со скидками по позициям и общей скидкой |
| `sort` | Сортировка чисел и ранжирование товаров по цене или марже |
| `hash` | SHA-256 текста в UTF-8 |
| `count_words` | Частоты слов с поддержкой кириллицы |
| `basket_affinity` | Совместные покупки, support, confidence и lift |
| `fib` | Число Фибоначчи для N от 0 до 10 000 |
| `factorial` | Факториал для N от 0 до 1 000 |

Денежные расчёты выполняются через Decimal с округлением до сотых. Денежные суммы и большие целые возвращаются строками, чтобы сохранить точность.

## Использование

```python
from basketnet.tasks import execute

print(execute("sum", [10, 20, 30]))
print(execute("basket_affinity", [["Молоко", "Хлеб"], ["Молоко", "Масло"]]))
```

Примеры входных данных в JSON находятся в `examples/`: чек со скидками, товары для сортировки и набор потребительских корзин.

## Тесты

```shell
python -m unittest tests.test_tasks -v
```

Проверяются суммы, скидки, округление, сортировка, SHA-256, частотный анализ, метрики пар товаров, большие целые и некорректные данные.
